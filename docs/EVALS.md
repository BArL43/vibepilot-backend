# Осознанная работа с ИИ и evals

## Почему две модели

Генератор концепций не выбирает собственную работу. При наличии двух текстовых
моделей `/capabilities` critic получает другую модель. Это снижает
self-evaluation bias, но не объявляется гарантией качества.

## Проверяемая рубрика

Critic обязан вернуть JSON и поставить каждой концепции четыре оценки 0–10:

- `clarity` — понятность оффера;
- `audience_fit` — соответствие аудитории из брифа;
- `distinctiveness` — различимость с типовой рекламой;
- `claims_safety` — отсутствие недоказуемых обещаний.

`total` — простая сумма. Это прозрачный ranking, а не вероятность конверсии.
Ответ, который не парсится как JSON, сохраняется как raw text и не подменяется
придуманной структурой.

## Что не измеряется

Без показов, кликов и продаж нельзя честно оценить CTR, CPL или ROMI. VibePilot
не выводит эти показатели из текста модели. Следующий production-eval должен
соединять receipt конкретного креатива с фактическими рекламными метриками.

## Набор тестов

- разные модели для generation и critic, если каталог позволяет;
- structured critic result попадает в banner payload и receipt;
- invalid JSON не ломает workflow;
- модель/цена не существует вне `/capabilities` или `/estimate`;
- counterfactual planner не использует скрытый quality score;
- решение approval объясняется числовой политикой;
- upstream error не становится успешным AI-результатом.
- скачок цены либо вызывает approval, либо приводит к проверяемому fallback;
- optional video действительно удаляется до `generate`, если не входит в конверт;
- сумма generation costs/refunds независимо сверяется с дельтой баланса;
- подмена любого поля receipt ломает Ed25519 verification.

## Следующий eval после live-run

Первый настоящий receipt становится golden trace, но не «ответом под тест».
Из него фиксируются только протокольные инварианты: наличие реальных IDs,
совпадение сметы/факта, корректная подпись и отсутствие превышения конверта.
Текст и изображение не сравниваются с заранее сочинённым эталоном — для
недетерминированной генерации это создало бы ложную уверенность.
